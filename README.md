# Ricky — Cybersecurity × Software × Hardware

Personal portfolio for Ricky, an engineer focused on cybersecurity, cloud-native software, Linux, networking and experimental hardware.

## ✦ Portfolio

Live site: **Ricky — build, break, learn, repeat**

The interface is designed as a living cyber lab: interactive network-grid background, terminal-inspired UI, motion, responsive layouts and project cards that expose the engineering story behind the work.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
